You are implementing Track A of a design spec for the Homerun Practice app

## Goal

Add skill-level/progression data and a new "Roadmap" view to the drill
library so it reads as a searchable, filterable, professional path from
Introductory (5–8U) through U15 (capped display at 12–15U). The sync script
(`scripts/sync-drills.mjs`) gains a `stage` field per drill/plan (explicit
from KB frontmatter when present, computed via a fallback table otherwise)
plus two new text fields (`progressionNotes`, `ageNotes`) parsed from KB
content that already exists in the source markdown but is currently
discarded by the sync script. The app then exposes a Level filter, a Level
badge, progression/prerequisite info in the drill detail modal, and a new
Roadmap view showing each skill category as a 4-stage ladder that reuses the
existing "load plan into builder" behavior. This requires zero KB content
changes — the fallback table makes it fully functional today.
